# Cetking Desk

Enquiry · Student · Alumni dashboard demo.

**Live demo:** https://cetkinglearning.github.io/cetking-desk/

**Repo:** https://github.com/CetkingLearning/cetking-desk

Static HTML app. Demo data is stored in the browser (`localStorage`).

## Pages

If the live link 404s for a minute after the first push:

1. Repo → **Settings** → **Pages**
2. Source: **GitHub Actions** (or **Deploy from branch** `main` / `/`)
3. Wait 1–2 minutes and open the URL above.

## Rooms

- Enquiry — My queue, New, Hot, Warm, Cold, Unassigned, Lost
- Students — attendance, mocks, fees, leftover close
- Alumni — college declared or staff close
